Personal Restic Backup

Privacy policy

Last updated: 18 September 2026

Purpose and scope

Personal Restic Backup is a single-user desktop configuration. It creates encrypted backup repositories in the owner's own Google Drive account. It is not offered as a service to other users.

Google data accessed

The client requests the Google Drive drive.file scope. This permits access to files created by, or explicitly opened with, the client. The configured backup accesses only the encrypted repository objects it creates. It does not request general access to unrelated files in the owner's Drive.

How data is used and stored

  • Selected source data is encrypted locally by restic before it is uploaded.
  • Encrypted repository objects are stored in the owner's Google Drive account.
  • The Google OAuth token is stored locally on the owner's Mac and is not transmitted to a developer server.
  • Data is used only to create, verify, maintain, and restore the owner's backups.

Sharing and disclosure

No Google user data or backup content is sold, shared for advertising, or disclosed to third parties. Google Drive acts solely as the storage destination chosen by the owner. The site uses no analytics or tracking code.

Retention and deletion

Encrypted backups remain in the owner's Google Drive until the owner deletes them. The current backup configuration does not automatically prune repository data. Revoking OAuth access stops future access but does not itself delete existing backup objects.

Security

Restic encrypts backup content and metadata before upload. Local OAuth and repository credentials are protected on the owner's Mac. No internet-facing backup server is operated.

Google API Services policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Control and contact

The owner can revoke access at any time through Google Account connections. Questions may be directed through the GitHub account hosting this policy.
