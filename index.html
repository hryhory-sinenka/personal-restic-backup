Single-user backup utility

Personal Restic Backup

Personal Restic Backup is a private desktop backup configuration used by its owner to store encrypted, versioned backups in the owner's Google Drive account. It uses restic for local encryption and snapshots and rclone for transport to Google Drive.

This is not a commercial service or a public application. It has no hosted application server, advertising, analytics, or public user registration.

Google Drive access

The desktop client requests the narrow drive.file permission. Its configured use is limited to creating, listing, reading, verifying, restoring, and maintaining the encrypted backup objects that it creates in the owner's Drive. It does not inspect unrelated Drive files.

Data handling

Backup data and filenames are encrypted on the owner's Mac before upload. No backup content, Google account data, or usage information is sent to the developer or sold or shared with third parties.
